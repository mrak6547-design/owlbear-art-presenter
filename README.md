# Art Show for Owlbear Rodeo

Standalone static Owlbear Rodeo extension. No npm build is required for the published files.

## Features
- GM panel with Owlbear image picker.
- Show to everyone via room metadata.
- Show only to GM locally.
- Each viewer can close the modal for themselves.
- GM can close the current presentation for everyone.
- Full-screen modal, zoom, pan and mobile pinch gestures.
- Local GM history of up to 20 images.
- Context-menu action for selected IMAGE items.

## Publish
Host this folder as a static site. The extension manifest is `manifest.json`.
