# Занавес — расширение для Owlbear Rodeo

Мастер одним кликом показывает игрокам арт почти **на весь экран**: внешность
NPC, локацию, артефакт, карту — любую картинку, которая уже есть в хранилище
или на сцене стола.

- 🖼️ **Почти весь экран** — арт открывается в полном размере на тёмном фоне.
- 🏆 **Золотая рама** с уголками и подписью (название + «Представляет …»).
- ✖️ **Крестик** — закрыть картинку; игрок может закрыть и сам, у себя.
- 📱 **ПК и телефоны** — зум колесом, щипком, двойным тапом, перетаскивание.
- 🎭 Эффект поднимающегося **занавеса** при показе.
- 🕵️ **ПКМ по картинке на сцене** → «Показать игрокам» тоже работает.
- 🎛️ Панель мастера: поиск, фильтры (NPC / локации / артефакты / карты),
  показ по ссылке, индикатор «Сейчас на экранах».

## Быстрая установка

**Самый простой способ — GitHub Pages (уже настроен в этом репозитории):**

1. В этом репозитории смержите запрос на слияние (Pull Request) — в нём лежит
   папка `plugin/` с уже собранным плагином. Это одна зелёная кнопка
   **Merge pull request**.
2. Подождите 1–2 минуты, пока GitHub Pages соберёт сайт заново.
3. Откройте комнату Owlbear Rodeo → **⊕ / Add Extension** → вставьте ссылку:
   `https://mrak6547-design.github.io/owlbear-art-presenter/plugin/manifest.json`
4. Включите расширение (тумблер рядом с «Занавес»).

Всё! У мастера появится кнопка **Занавес** в верхнем левом углу комнаты.

**Альтернатива — любой статический хостинг:**

1. Соберите проект: `npm run build` (появится папка `dist/`).
2. Загрузите содержимое `dist/` на Netlify, Vercel, Cloudflare Pages.
3. Скопируйте ссылку на `manifest.json` — она заканчивается на `/manifest.json`.
4. В комнате Owlbear: **⊕ / Add Extension** → вставьте ссылку → включите.

## Как пользоваться

- **Показать:** откройте «Занавес» → кликните по картинке → она мгновенно
  откроется у всех (в том числе у вас) почти во весь экран.
- **Или:** выделите картинку на сцене → ПКМ → **«Показать игрокам»**.
- **Скрыть:** на панели нажмите **«Скрыть»** (занавес опустится у всех).
  Крестик у игрока закрывает картинку только у него — мастер всегда может
  снять показ повторным «Скрыть» или запустить новый арт.
- **Зум:** колесо мыши / щипок на телефоне / двойной тап; перетаскивайте
  картинку пальцем или мышью, кнопки «+ / − / 100%» снизу слева.
- **По ссылке:** в панели раскройте «Арт по ссылке» и вставьте URL картинки
  с названием — можно показывать арты, которых ещё нет на сцене.

## Разработка

```bash
npm install
npm run dev        # http://localhost:5173
```

В комнате Owlbear добавьте расширение по адресу
`http://localhost:5173/manifest.json` — тогда панель подключится к живой
сцене (пока dev-сервер запущен). Обновляйте расширение в комнате после
изменений: «Manage Extensions» → обновить.

```bash
npm run build      # сборка в dist/ (+ проверка типов)
npm run preview    # локальный предпросмотр собранного dist/
```

## Структура

```
index.html            — приложение расширения (?mode=action — панель, ?mode=viewer — показ)
background.html       — фоновая страница (собирается Vite в dist/background.html)
public/manifest.json  — манифест Owlbear Rodeo (это ссылка для установки)
public/icon.png       — иконка расширения
src/background.ts     — контекстное меню + синхронизация показа на всех клиентах
src/lib/obr.ts        — обёртка над SDK: состояние показа, картинки сцены
src/pages/ActionPanel.tsx — панель мастера
src/pages/ViewerPage.tsx  — полноэкранный показ (рама, жесты, крестик)
```

Показ синхронизируется через metadata комнаты: мастер пишет состояние
(`zanaves/state`), фон-скрипт каждого клиента открывает/закрывает
полноэкранный модал — поэтому арт появляется у всех одновременно.
