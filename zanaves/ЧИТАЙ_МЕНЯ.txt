ЗАНАВЕС — расширение для Owlbear Rodeo (версия 2.1.0)
=====================================================

Мастер одним кликом показывает игрокам картинку почти на весь экран:
NPC, локацию, артефакт, карту — любую картинку, которая уже есть
в хранилище или на сцене стола.

ЧТО ВНУТРИ АРХИВА
-----------------
- Папка zanaves — ГОТОВЫЙ плагин, загружать на хостинг нужно именно её.
- Внутри: manifest.json (обязательно в корне), assets/, images/,
  background.html, index.html, vercel.json (CORS для Owlbear).
- Больше ничего устанавливать не нужно: это готовый файл, а не исходники.

КАК ЗАГРУЗИТЬ (Vercel Drop, без Git и терминала)
-------------------------------------------------
1. Распакуйте архив и найдите папку zanaves.
2. Откройте в браузере сайт: vercel.com/drop
3. Перетащите папку zanaves (или архив целиком) в окно браузера.
4. Нажмите Deploy. Через ~15 секунд появится адрес вида
   https://что-то.vercel.app — скопируйте его.

КАК ПОДКЛЮЧИТЬ В OWLBear RODEO
------------------------------
1. В Owlbear откройте Manage Extensions (меню слева).
2. Если там уже есть «Занавес» — УДАЛИТЕ старую запись,
   иначе расширение может показать старую версию.
3. Нажмите Add Extension и вставьте:
   https://что-то.vercel.app/manifest.json
4. Включите тумблер «Занавес».
5. Обновите страницу: Ctrl+Shift+R (на Mac — Cmd+Shift+R).
   Игрокам тоже нужно обновить страницу.

КАК ПОЛЬЗОВАТЬСЯ
----------------
- Откройте панель «Занавес» на панели инструментов.
- Пульт мастера: список картинок со сцены, поиск, фильтры,
  кнопка «Хранилище» (выбор из библиотеки ассетов),
  «Арт по ссылке» для картинки из интернета.
- Клик по картинке — показ всем игрокам почти на весь экран
  в золотой раме с подписью и крестиком.
- Кнопка «Несколько» — отметьте арты галочками и покажите их по очереди
  (в показе появятся стрелки ‹ ›).
- «Шёпот мастера»: короткая реплика, которую игроки видят под названием.
- Мастер может закрыть показ у всех кнопкой «Скрыть у всех» в самом окне показа.
- Правой кнопкой по картинке на сцене → «Показать игрокам».
- В показе: зум колесом/щипком/двойным тапом, перетаскивание,
  кнопка «Заполнить/Целиком» (по умолчанию — целиком, без обрезки),
  стрелки листалки, если мастер выбрал несколько картинок.
- Игроки видят показ автоматически и могут закрыть его сами у себя.
